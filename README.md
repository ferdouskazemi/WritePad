# Write Pad

A web notepad that feels like writing on a living sheet of 1930s cartoon paper.

## Quick start

```bash
cp .env.example .env.local
# fill in .env.local
npm install
npm run dev
```

## Available scripts

| Command | Description |
|---|---|
| `npm run dev` | Start development server |
| `npm run build` | Production build |
| `npm run lint` | ESLint |
| `npm run type-check` | TypeScript check |
| `npm test` | Vitest unit tests |
| `npm run test:e2e` | Playwright e2e tests |
